# Fetch Users API Project

A responsive user listing website built using HTML, CSS, and JavaScript. User data is fetched from the JSONPlaceholder API and dynamically displayed on the frontend.

## 🚀 Features

- Fetches user data from a public API
- Uses JavaScript `fetch()` with `async/await`
- Dynamically creates user cards using DOM manipulation
- Displays:
  - Name
  - Email
  - Phone
  - City
  - Company
- Loading message while fetching data
- Error handling using `try`, `catch`, and `finally`
- Responsive design for mobile devices
- Card hover transition effect

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- DOM Manipulation
- JSONPlaceholder API
